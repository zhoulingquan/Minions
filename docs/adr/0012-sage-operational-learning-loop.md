# ADR-0012: SAGE 采用稳定内核与可插拔智能增强

## Status

Accepted

## Context

SAGE 已具备较完整的经验数据模型和治理门禁，但自动复盘、中文语义召回和会话历史衔接尚未真正运行。完全依赖大模型会引入费用、网络和非确定性故障；只使用规则又难以覆盖相似业务的不同表达。系统还必须维持多租户隔离，并确保 Agent 不能自行宣称业务成功。

## Decision

采用稳定规则内核和可插拔智能增强：

- 多租户 `TenantPrincipal` 是 SAGE 唯一身份来源；
- 每次正常执行生成不可召回的临时复盘草稿，结果由可信主体确认；
- 默认提供本地确定性向量基线，允许生产配置 OpenAI 兼容向量服务；
- 向量只参与候选发现和排序，治理、权限、证据门槛保持确定性；
- Scroll 恢复为会话历史层，SAGE 保持跨会话业务经验层；
- 所有智能增强失败时安全降级，不阻断业务响应。

## Consequences

### Positive

- 不依赖外部模型也能持续积累案例和产生可审核草稿。
- 配置向量模型后可提升中文近义业务召回，同时保留可解释降级。
- 业务经验与原始会话各司其职，减少无限上下文和错误知识发布。
- 多租户权限、审批与回滚继续作为不可绕过的硬边界。

### Negative

- 本地确定性向量只能提供相似表达基线，不能等同于高质量语义模型。
- 管理员仍需确认业务结果和共享/高风险知识。
- SQLite 余弦扫描只适合开发和中小数据量。

## Alternatives Considered

- 全部依赖大模型：因可用性、成本和非确定性被拒绝。
- 只做关键词和固定规则：因中文近义召回能力不足被拒绝。
- 立即引入独立向量库、图数据库和消息队列：因运维成本超出当前中小企业场景被拒绝。
