# SAGE 2.2 Operational Learning Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Turn the governed SAGE kernel into an operational multi-tenant learning loop that captures ordinary work, drafts reusable lessons, supports human verification, performs real vector persistence/recall, and exposes the complete memory center.

**Architecture:** Keep `TenantPrincipal` as the only identity root. Add a conservative reflection engine and semantic index behind fail-soft protocols, persist vectors in both SQLite and PostgreSQL adapters, restore Scroll as the session-memory layer, and extend existing APIs/UI without bypassing SAGE governance.

**Tech Stack:** Python 3.11+, FastAPI, Pydantic, SQLite, PostgreSQL/pgvector, React/TypeScript/Ant Design, pytest, Vitest.

**实施状态：** 已完成。SAGE 后端定向测试 142 项、前端定向测试 6 项、Ruff、
Python 编译与 Vite 生产资源构建均通过；本地 8088/5173 服务已使用本版本启动，
经验成长页面的 10 组管理接口均返回 200。

仓库级 `npm run build` 的 TypeScript 前置检查仍受 SAGE 之外既有页面的未使用变量、
恒真表达式等错误影响；本轮改动文件的 ESLint 与实际 Vite 构建已通过，阻断项未在
本任务中越界修改。
