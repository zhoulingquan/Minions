# SAGE 2.2 业务自成长记忆系统设计

**状态：** 已确认并进入实施
**日期：** 2026-07-13
**基线：** 多租户 2.1 + SAGE 完整经验系统

## 1. 结论与范围

SAGE 2.1 已具备租户隔离、经验对象、治理策略、案例复核、心得审批、夜间整理和回滚，但真实业务仍缺少稳定的自动复盘、实际语义召回和完整管理入口。2.2 的目标是让普通聊天、渠道、Cron 和 ACP 执行都进入同一条可观察的成长链路：

```text
可信租户主体 → 业务迹证 → 待复核案例 → 自动复盘草稿
      → 结果确认 → 心得修订/验证 → 发布知识 → 相似任务召回
      → 使用反馈 → 效用调整 → 夜间整理 → 手册沉淀/回滚
```

本轮不另建用户体系，不允许请求正文声明租户、用户或业务成功。身份只来自多租户控制平面；业务结果由服务端信号或有权限的成员确认。

## 2. 当前评估校准

| 原评估断点 | 当前状态 | 2.2 动作 |
|---|---|---|
| 本地和渠道没有可信 SAGE 身份 | 已由 `TenantPrincipal` 与运行作用域修复 | 增加全入口回归测试 |
| 没有案例复核与心得审批 | 已有后端和基础页面 | 增加心得修订、知识/手册管理 |
| 不会自动总结心得 | 仍存在 | 新增迹证驱动的结构化复盘器 |
| 向量召回未接入 | 仍存在 | 注入向量服务、SQLite 向量落库与检索 |
| 夜间整理只做精确规则 | 部分存在 | 增加语义相似候选；保留规则兜底 |
| AUTO 不会自动应用 | 已修复 | 补充边界测试，不重复实现 |
| 多租户仅数据层准备 | 已接入 2.1 控制平面 | 保持同一主体和 PostgreSQL RLS |
| Scroll 配置与构建矛盾 | 仍存在 | 恢复会话记忆层并明确与 SAGE 分工 |

## 3. 方案比较

### 方案 A：所有复盘与整理依赖大模型

表达质量高，但模型故障、费用和提示注入会阻断成长主链路，不适合中小企业长期稳定运行。

### 方案 B：只使用固定规则和关键词

运行最稳定，但无法有效处理中文近义表达，心得质量也容易退化成对回答的复制。

### 方案 C：稳定规则内核 + 可插拔智能增强（采用）

规则内核负责身份、迹证、状态机、保守复盘、审核、回滚和降级；向量与更高级复盘通过受限接口接入。默认开发环境使用本地确定性中文向量，不访问网络；生产可配置 OpenAI 兼容向量端点。任何智能能力失败都只记录降级，不丢失案例、不跳过审核。

## 4. 分层记忆架构

1. **工作记忆**：当前模型上下文，短时、速度优先。
2. **会话记忆（Scroll）**：同一会话的原始历史和工具结果，按会话与 Agent 隔离，用于找回具体上下文。
3. **业务经验（SAGE）**：跨会话的案例、知识、心得、手册和反馈，按租户、用户、Agent、项目等作用域治理。
4. **成长治理**：证据门槛、风险分级、审批、自动应用、版本和回滚。

Scroll 不再被称为长期业务记忆，也不会直接发布知识；SAGE 不保存无限原始聊天，而是引用可审计迹证并形成受治理的经验。

## 5. 自动复盘

每次正常响应都会保存用户目标和 Agent 输出，并为待复核案例生成低置信度结构化草稿。草稿至少包含：

- 业务目标与场景；
- 已采取的做法；
- 服务端观察到的结果；
- 适用条件和风险提示；
- 证据案例与迹证来源；
- `provisional=true`，明确尚未核验。

待复核草稿不能进入召回。管理员确认成功或部分成功后，复盘器使用确认摘要覆盖或增强草稿；只有满足独立案例证据门槛并完成审批后才发布为有效知识。失败案例保留为案例和反馈信号，不自动形成“成功做法”。

## 6. 语义召回与整理

向量服务采用可插拔协议：

- `local-hash`：默认开发实现，针对中文字符、二元组和英文词生成确定性归一化向量；无网络、可复现，用作稳定降级基线。
- `openai-compatible`：生产可选，通过独立环境变量配置端点、模型和密钥；超时或返回异常时回退到词法/结构化召回。
- SQLite 在独立向量表中保存向量并用余弦相似度检索；PostgreSQL 使用 pgvector。

语义相似只用于发现候选和排序，不能绕过作用域、密级、有效期和状态过滤。夜间整理把高相似度条目生成“可能重复/可能冲突”候选，仍经过现有治理门禁。

## 7. 非功能要求

- 正常召回 p95 目标小于 500ms；向量超时最多 1.5 秒且可降级。
- SQLite 面向单机开发和小规模验证，语义扫描上限 2,000 条；生产仍要求 PostgreSQL。
- 所有列表和变更保持租户、作用域和密级校验。
- 不存储密码、令牌和凭据；复盘输入有长度上限，渲染继续视历史为非权威数据。
- 成长作业幂等；失败可重试；任何已发布变化可追溯和回滚。

## 8. 完成标准

1. 普通免登录开发聊天、登录 HTTP、渠道、Cron 和 ACP 均能形成租户绑定案例。
2. 正常响应自动出现待复核案例和低置信度心得草稿。
3. 管理员可确认结果、修订心得、批准发布；发布后能被下一次相似任务召回。
4. SQLite 实际保存并检索向量，中文不同措辞能获得语义候选。
5. 页面具备案例、知识、心得、手册、反馈、整理和运行记录入口。
6. Scroll 按配置实际接入，和 SAGE 的职责、权限及保留周期清晰。
7. 跨租户、越权审批、未核验发布和智能能力故障测试全部失败关闭或安全降级。
